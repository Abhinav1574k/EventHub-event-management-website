# EventHub - Event Management Website

A responsive event management website developed as part of Task 6 of the Web Development Internship at Veda Technology.

The application allows users to browse upcoming events, filter events by category and date, view event details, and submit a validated registration form.

## Project Overview

EventHub is a frontend event discovery application designed to provide a simple and responsive interface for finding and registering for events.

The project demonstrates dynamic content rendering, category filtering, date filtering, reusable JavaScript functions, event detail views, and form validation.

---

## Features

- Responsive event listing
- Dynamic event cards
- Category filtering
- Date filtering
- Multiple filters
- Event detail view
- Event information display
- Registration form
- Form validation
- Registration success state
- Empty results state
- Responsive mobile navigation
- GitHub Pages deployment
- GitHub Actions automation
- Git rollback support
